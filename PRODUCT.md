# Product

## Register

brand

## Users

Hiring managers, design-minded engineering teams, collaborators, and peers who need to understand Hunter Bastian's taste, implementation ability, and project judgment quickly. They are usually scanning the portfolio between other work, so the site should make the strongest work feel edited, concrete, and easy to enter.

## Product Purpose

This portfolio presents Hunter's design-engineering work, case studies, experiments, and resume in one cohesive web surface. Success means a visitor leaves with a clear sense of craft, range, and follow-through, then opens a project, downloads the resume, or gets in touch.

## Brand Personality

Calm, tactile, coastal. The direction should blend Mediterranean atmosphere, Zara-like editorial restraint, and Copenhagen utility: warm without becoming beige, polished without feeling corporate, refined without losing personality.

## Anti-references

Avoid generic AI landing-page grammar: repeated card grids, loud gradient text, oversized rounded panels, decorative glass, default SaaS hero metrics, and tiny uppercase labels above every section. Avoid turning the site into a fashion editorial if it makes the project work harder to scan.

## Design Principles

1. Let the work lead: imagery, case-study artifacts, and project surfaces carry more weight than explanatory copy.
2. Keep atmosphere ambient: coastal color, texture, and light should frame the work, not compete with it.
3. Make every list feel edited: rows, archive items, and project navigation should read like a curated catalog.
4. Preserve practical clarity: contact, resume, and project entry points need to remain obvious and fast.
5. Prefer tactile restraint: subtle borders, paper-like surfaces, and precise spacing beat decorative effects.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Preserve keyboard focus states, readable type sizes, descriptive link labels, useful alt text for meaningful imagery, and reduced-motion fallbacks for motion-heavy interactions.

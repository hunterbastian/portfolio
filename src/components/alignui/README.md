# Portfolio AlignUI components

Adapted from AlignUI's free MIT-licensed components:
https://github.com/alignui/alignui-nextjs-typescript-starter
https://alignui.com/docs/v1.2/ui/button
https://alignui.com/docs/v1.2/ui/drawer
https://alignui.com/docs/v1.2/ui/slider
https://alignui.com/docs/v1.2/ui/select
https://alignui.com/docs/v1.2/ui/switch
https://alignui.com/docs/v1.2/ui/tag
https://alignui.com/docs/v1.2/ui/modal

Retains the Radix primitives and composition patterns; maps styling to the portfolio's existing theme and CSS modules. Removes unused variants/helpers and uses existing Lucide icons. Controls have 44px targets, visible keyboard focus, and reduced-motion support. This is a selective source integration, not a global theme replacement. MIT notice in LICENSE.

The static Tag marks project disciplines. Modal powers the case-study image viewer with a focus trap, Escape/outside dismissal, scroll locking, and focus restoration. Page composition uses a custom responsive editorial grid.
